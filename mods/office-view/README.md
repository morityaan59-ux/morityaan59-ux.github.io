# office-view（Claude Code mod）

セッション間の指示を、キャラが廊下を通って伝えに行くオフィス図で見せる mod です。
サイドバーの横に置けるよう、階を縦に積んだ縦長の図にしています。
設計の経緯は Issue #8 にあります。

## 図の見方

- 階ごとに部屋があり、右の廊下（階段）でつながっています。
- 名札は「案件のキャラ」（例: ヤフーフリマのモモ）。
- 指示を受けて、まだ返事をしていない席は名札に赤い「!」が付き、指示の要約が吹き出しで残ります。
- 名札の下は状態です。「指示あり 3日前」「送信 5分前」「在席」「退勤」のどれか。
- セッションが動いていない席は薄く描き、「退勤」と出ます。

## 入れ方（ローカルの Claude Code）

このフォルダを PC の好きな場所に置き、**全部のセッション**で読み込みます。

```sh
claude --plugin-dir /path/to/office-view
```

デスクトップアプリから起動するセッションでは、`~/.claude/settings.json` の `env` に書きます。

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/office-view" } }
```

## 使い方

| コマンド | 動き |
|---|---|
| `/office` | オフィス図のパネルを開く |
| `/office desk ソラ/本社` | このセッションの席を登録する（セッションごとに 1 回） |
| `/office desk` | 登録中の席を表示する |
| `/office demo` | デモの指示を 4 件流して動きを確認する |
| `/office clear` | 連絡板を空にする |

## 仕組み

- 送る側のセッションで `session.send` を検知し、「誰から誰へ・要約 1 行・時刻」を共有ストアに書きます。本文は残しません。
- 受ける側のセッションで `session.receive`（他セッションからの配達）を検知し、「受け取った」を書きます。
- 席を登録したセッションは 30 秒ごとに在席の合図を書きます。90 秒合図が無い席は「退勤」になります。
- パネルを開いたセッションが 0.5 秒ごとに共有ストアを読み、新しい行をアニメで再生します。
- 共有ストアは Claude Code 設定フォルダ内の JSON ファイルです。同じ PC 上のセッション同士でだけ共有されます。
- 各セッションは自分専用のキー（`log:<セッションID>`）にしか書かないので、同時に書いても消し合いません。

## フロアの変更

`office.json` を編集します。保存するとホットリロードで反映されます。

- `floors`: 上の階から順に、階の名前（`name`）と席の一覧（`desks`）。`role` は部屋の左上の役割名、`subtitle` は階の名前の横の説明
- `colors`: キャラ名 → 色
- `labels`: 席名 → 名札（「案件のキャラ」の代わりに出す名前）

席名はセッション名の `[キャラ/案件]` の中身と同じにします。宛先が見つからない相手は、1 階の入口に来客として描きます。

## 画面ごとの描き方

| 画面 | 描き方 |
|---|---|
| デスクトップアプリ、VS Code | SVG の縦長の図。キャラが廊下を歩く |
| ターミナル | 色付きセルの小さなキャラと名札。歩くアニメは説明行だけ |

## 置き場所について

mod のパネルは会話の横に開きます。Claude Code の左のセッション一覧そのものの中には置けません（アプリの外枠は mod から変えられないため）。縦長にしてあるので、会話の横に細く開けばサイドバーのように使えます。
