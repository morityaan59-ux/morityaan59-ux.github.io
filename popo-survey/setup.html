ヒアリング回答の受け取り設定（ポポさん用）

所要時間：5〜10分。ポポさんのGoogleアカウントで行ってください。

この設定をすると…

スタッフが「ポポさんに送信する」を押した回答が、ポポさんのGoogleスプレッドシートに1人1行で自動保存され、ポポさんのGmailにも通知が届きます。

スプレッドシートはポポさんのGoogleドライブにあるので、共有しない限りポポさん以外は見られません（アンケートページを作った人にも見えません）。

  1. 新しいスプレッドシートを作る
    sheets.new を開くと空のスプレッドシートができます。名前は「スタッフヒアリング回答」などに変えておくと分かりやすいです。
  2. Apps Script を開く
    メニューの 拡張機能 → Apps Script を押します。新しいタブでコード画面が開きます。
  3. 下のコードを貼り付ける
    最初から入っている function myFunction() {…} を全部消して、下のコードをそのまま貼り付け、💾（保存）を押します。 
    
    
    4. 
    
  4. 
      ウェブアプリとして公開する
    
      右上の デプロイ → 新しいデプロイ → 歯車アイコン → ウェブアプリ を選び、
      
      
        
    • 次のユーザーとして実行：自分
      • 
        
    • アクセスできるユーザー：全員
      • 
      
    
      にして デプロイ を押します。
      
    「全員」は「誰でも回答を送れる」という意味で、スプレッドシートが見えるわけではありません。
    
    
    5. 
    
  5. 
      アクセスを許可する
    
      「アクセスを承認」→ 自分のアカウントを選ぶ → 「このアプリは Google で確認されていません」と出たら 詳細 → （安全ではないページ）に移動 → 許可。
    
      自分で作ったスクリプトなので、この警告は毎回出るものです。スプレッドシートへの書き込みとメール送信の許可を求めています。
    
    6. 
    
  6. 
      URL を送る
    
      表示された ウェブアプリのURL（https://script.google.com/macros/s/…/exec）をコピーして、アンケートページの管理者に送ってください。管理者がページに設定すると、送信ボタンが使えるようになります。
      
    このURLは「送信用の宛先」なので、知られても回答は読めません。
    
    
    7. 
  


  
届いた回答の見方

  
    
    
  • スプレッドシートの「回答」シートに、1回の送信につき1行追加されます。
    • 
    
  • 「回答テキスト」列に全回答が読みやすい形で入っています。同じ内容がメールでも届きます。
    • 
    
  • スタッフが書き直して再送信した場合は新しい行が増えます。同じ名前のいちばん下の行が最新です。
    •
